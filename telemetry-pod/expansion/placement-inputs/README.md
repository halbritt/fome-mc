# Expanded-pod placement inputs and rejected side seed

`side-assignment.json` gives all 327 circuit instances an explicit candidate side, preserving whole schematic groups. Analog, ADC, storage, supervision, diagnostics, thermistor and test-point groups go to the back; connector, MCU/radio, GNSS, IMU, interface and supply groups remain front. There are 169 back and 158 front circuit footprints, plus four unchanged front-side mounting holes. This is an engineering starting point, not thermal, electrical locality, underside-clearance or routing approval. Group membership alone does not enforce decoupling distance, power-loop geometry or isolation.

`anchors.json` preserves the three historical radio/SMA/IMU candidate anchors and corrects J1 to the current connector drawing: (45,55.5) mm, rotation zero, aligns the footprint's +9.5 mm board-edge guide with Y=65. The 77.9 mm courtyard spans X=6.05..83.95 and extends to Y=87.85, requiring 22.85 mm of bottom overhang. It is not shrunk to fit. The connector-candidate source review supports the guide; harness, panel, mating and cowl clearance remain unqualified. Hole courtyards describe only the existing hole footprint, not screw heads or standoffs.

`envelope.json` is a candidate revision of retained `historical-envelope.json`: J1 inset/overhang and id change, the withdrawn 12 mm obligation is removed, and the obsolete connector obligation is corrected to exact 1-776163-1. Historical stackup/profile/antenna references remain unresolved in this isolated declaration; `envelope-validation.json` reports structural pass and outcome unknown. It is not a qualified current fabrication envelope. No layer thickness or missing source is fabricated.

`seed.py` calls native KiCad Flip and rigid transforms on an isolated imported board. Source bytes remain unchanged. The seed's native component/pad/net membership matches the revised XML, and all side assignments match. **The seed is rejected, not adopted:** the unchanged placement adapter reports 867 violations: 843 custom properties, 16 mirrored arcs and eight custom pads. Only the four front anchor transforms are admitted. `write-scope.json` retains the full refusal.

`property-diagnostic.json` finds all 843 property failures disappear when the existing `_property_font_defaults` normalizer is applied diagnostically before flip comparison. KiCad adds default custom-field font thickness during save. This does not change software, fields or gate outcomes. Mirrored arcs and custom primitives remain separately unsupported; no general waiver is justified. The normalizer is already used for ordinary moves, and needs a qualified flip-path repair with mutation controls.

`rejected-seed.kicad_pcb.gz` and `seed-probe.json.gz` retain exact bytes and native observations. The rejected seed must not be used as accepted placement input or a manufacturing design. The source-independent board under `../probe-import` remains the imported baseline.

Run `verify.py` with the exact experimental software pinned in `../probe-import/software.json` on PYTHONPATH. It replays the refusal, side membership, native net correspondence and envelope validation. For fresh native generation use the KiCad Python interpreter with `seed.py --out` and a new path, then rerun the unchanged change-scope gate. A passing net comparison does not override its refusal.
